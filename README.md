# 残労働時間 for ジョブカン（非公式）

![](docs/Header.png)

ジョブカン勤怠管理（従業員マイページ）の出勤簿ページに、月規定労働時間に対する累計・残り時間・1日平均を表示する Chrome / Firefox 拡張機能です。

> [!WARNING]
> この拡張機能は個人が作成した**非公式拡張機能**です。
>
> ジョブカンを提供する株式会社DONUTSとは一切関係がなく、同社による承認や保証も受けていません。「ジョブカン」は株式会社DONUTSの登録商標です。
>
> ※ ジョブカンの利用には別途契約が必要です


## 表示内容
出勤簿の日別テーブルを拡張し、「累計労働時間」「残時間 / 残平均」列を追加します。

| 列 | 内容 |
|---|---|
| 累計労働時間 | 1日から該当日までの「労働時間」の合計 |
| 残時間 / 残平均 | 該当日終了時点での月規定労働時間の残り時間。該当日が今日だった場合は残りの勤務日数で必要な平均労働時間も表示する |


## プライバシー
拡張機能で読み込むページのデータは外部に送信せず、保存も行いません。計算はページを開いたときにブラウザ内だけで行います。


## ブラウザへのインストール
### Chrome
1. GitHub Release より `Chrome.zip` をダウンロードして、展開する
2. `chrome://extensions` を開き、右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」でダウンロードした `Chrome.zip` を選ぶ
